# 今天吃什么 · 转盘 🍜

一个帮你解决「今天吃什么」的转盘网页。点一下转盘，指针指到哪个就吃哪个。

## 功能

- 35 种食物：汉堡、炸鸡、拌面、螺蛳粉、鸭货、寿司、冒菜、关东煮、烧烤、糖水、快餐、牛杂、奶茶、凉面、饺子、粥、云吞、披萨、手抓饼、麻辣烫、食堂、手撕鸡、鱼、意面、泰餐、韩料、罐罐米线、牛肉面、砂锅粉、辣鸡粉、车仔面、火锅鸡、菌菇炒饭、炒饭、烤鸭
- 转动带缓动效果，随机落点
- 转出结果后弹窗大字显示，可「再转一次」或「就吃这个」
- 每样食物都配了对应的 emoji 表情
- 转动有“哒哒”音效，结果揭晓有提示音，右上角可一键静音
- 适配手机与电脑

## 本地使用

下载后直接用浏览器打开 `index.html` 即可，无需安装任何东西。

## 技术

纯 HTML + CSS + Canvas + 原生 JavaScript，单文件，零依赖。
